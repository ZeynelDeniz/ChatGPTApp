# ChatGPTApp

ChatGPTApp is an ASP.NET Core MVC application that lets users interact with OpenAI's language models through a chat interface, similar to ChatGPT.

It features asynchronous messaging, conversation history, and secure API key management.

## Features

- Chat with OpenAI models (e.g., GPT-3.5, GPT-4)
- Asynchronous communication (AJAX)
- Session-based conversation history
- Secure handling of API keys
- Clean MVC architecture

## Technologies

- ASP.NET Core MVC (.NET 8)
- C#
- JavaScript (AJAX)
- OpenAI API
- HTML / CSS (Bootstrap)



### Prerequisites

- [.NET 8 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)
- An OpenAI API key

### Installation
1. Clone the repository:
```bash
git clone https://github.com/ZeynelDeniz/ChatGPTApp.git
cd ChatGPTApp
```
2. Restore and build the project:
```bash
dotnet restore
dotnet build
```
3. Run the application:
```bash
dotnet run
```
